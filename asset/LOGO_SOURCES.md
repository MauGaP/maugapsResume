# Tool logo sources

- `typescript-logo.svg`: `ts-logo-512.svg` from the asset pack linked by the [official TypeScript branding page](https://www.typescriptlang.org/branding/), downloaded October 2026. Original artwork preserved.
- `locust-logo.svg`: inline SVG from the [official Locust website](https://locust.io/), downloaded October 2026. The SVG has explicit dimensions and white text for the portfolio's dark background; paths and green mark are preserved.
- `behavex-wordmark.svg`: local typographic label, not an official standalone logo. The [BehaveX repository](https://github.com/hrcorval/behavex) uses its name in the official `img/social_preview.png` graphic; no separate logo asset was found in the repository. The portfolio uses the name in bold light text rather than displaying the promotional banner at icon size.
