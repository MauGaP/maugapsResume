# Mauro Pedano's CV website

Personal CV and portfolio website at [maugap.com](https://maugap.com), built with HTML, CSS, JavaScript, and Bootstrap.

The website includes professional experience, technical skills, qualifications, personal projects, contact information, and downloadable one-page and two-page CVs.

## Local preview

From the repository directory, run:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open [localhost:8765](http://localhost:8765).

## Content

- `index.html`: profile, experience accordion, qualifications, project carousel, and contact section.
- `css/style.css`: styling and responsive layouts.
- `js/index.js`: tool-list interactions.
- `asset/resume/Mauro_Pedano_CV_One_Page.pdf`: condensed CV.
- `asset/resume/Mauro_Pedano_CV_ATS.pdf`: detailed CV.

Both CV downloads and the professional content were updated in October 2026.

Work descriptions are collapsed by default. Click a company header or use Enter/Space to expand it; opening another company closes the previous one.

The personal projects are [¿Quién Gobierna?](https://quiengobierna.com/), a collaborative civic information platform; ProjectFire, a 3D fire-building simulation prototype; ProjectBushcraft, a woodland exploration game project with documented systems design; and [Roll Initiative](https://github.com/MauGaP/rollinitiative), a real-time tabletop RPG initiative tracker.

ProjectFire and ProjectBushcraft are presented as projects in development. They have no public demo or repository link in the portfolio yet.
